# Flappy Birds 🐦

A **2D flappy-bird clone** built with **Godot Engine** using **GDScript**.
Flap through an endless pipe gauntlet and beat your high score.

![Screenshot](https://github.com/user-attachments/assets/fb4fdc65-13d7-4b52-b586-e206b487b81f)

---

## 🚀 Features

* Classic **tap-to-flap** gameplay
* Endless, randomly spawning pipes
* Score & persistent high score, saved locally
* Rotation-based flight animation and game-over/restart flow

---

## 🧠 Built With

| Technology       | Purpose                |
| ---------------- | ----------------------- |
| **Godot Engine** | Game engine             |
| **GDScript**     | Core game logic          |
| **Scenes**       | Modular game structure  |
| **Assets folder**| Sprites & sounds        |

---

## ▶️ How to Play

1. **Open in Godot Engine**
2. **Run the main scene**
3. **Controls**

   * Press flap key to flap and fly
   * Avoid pipes and the ground
   * Restart after game over
